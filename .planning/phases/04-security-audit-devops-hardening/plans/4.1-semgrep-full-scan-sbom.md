# Plan 4.1: Semgrep Full Scan + SBOM

## Scope

Run Semgrep's `p/security-audit` and `p/owasp-top-ten` rule packs against backend/ and frontend/, commit SARIF output. Generate Syft SBOM for backend Python deps. Both tools produce artifacts in `security/`.

## Requirements

- R-13 (Security/Audit/DevOps — artifact types: Semgrep results, SBOM)

## Critical items tested

- Semgrep scans run against both backend/ and frontend/
- SARIF output is valid JSON
- SBOM generates without error
- Artifacts are reproducible (re-running the commands produces similar output)

## Code deliverables

### 4.1.1 — Semgrep standard suite results
- Run: `semgrep --config p/security-audit --config p/owasp-top-ten --sarif backend/ > security/semgrep/results-backend.sarif`
- Run: `semgrep --config p/security-audit --sarif frontend/src/ > security/semgrep/results-frontend.sarif`
- Committed SARIF files capture findings at time of scan

### 4.1.2 — Custom rule results
- Run: `semgrep --config security/semgrep/rules/ --sarif backend/ > security/semgrep/custom-rule-results.sarif`
- (Already verified: 0 findings on clean codebase)

### 4.1.3 — Syft SBOM (backend)
- Run: `syft dir:backend/ -o cyclonedx-json > security/sbom/backend-sbom.cdx.json`
- If syft not available, document the command in a README within security/sbom/
