# Plan 2.3: Report + Diff Pages

## Scope

Build the findings report page (severity-grouped view) and scan diff page (added/removed/unchanged with drift detection). Wire React Router navigation between all pages.

## Requirements

- R-04 (Frontend — report and diff pages, centralized API client)
- Success criteria 2, 3 from ROADMAP Phase 2 (severity-grouped report, diff with drift)

## Code deliverables

### 2.3.1 — Findings report page
- `frontend/src/pages/ScanReportPage.tsx`:
  - Fetches `api.getReport(scanId)` on mount
  - **Summary bar:** count per severity with colored pills (Critical=red, High=orange, Medium=yellow, Low=gray) — or simplified severity colors
  - **Findings list:** grouped by severity, sorted Critical→Low
  - Each finding card shows:
    - Rule ID badge (e.g. `MCP-001`)
    - Severity badge (colored)
    - Title
    - Subject (tool/resource/prompt name)
    - Description
    - Remediation text
  - **States:**
    - Loading: skeleton cards
    - Not found: "Scan not found" with link back to scans
    - Not completed: "Scan is still running" with auto-redirect
    - Empty findings: "No findings — clean scan" with green checkmark
    - Error: error message with retry button

### 2.3.2 — Scan diff page
- `frontend/src/pages/ScanDiffPage.tsx`:
  - URL: `/scans/:id/diff/:otherId`
  - Fetches `api.diffScans(id, otherId)` on mount
  - **Sections:**
    - **Added findings** (green background) — findings in scan_id not in other_id
    - **Removed findings** (red background) — findings in other_id not in scan_id
    - **Unchanged findings** (neutral) — present in both
    - **Drift warnings** (yellow/orange) — severity changes or silent removal with description
  - Each finding in a section shows: rule_id, severity, subject, description
  - Drift items highlighted with warning icon and "Drift detected" label
  - **States:**
    - Loading: skeleton
    - Error: scans not found, same target mismatch, not completed
    - Both scans identical: "No differences found"

### 2.3.3 — Navigation update
- React Router updated in `App.tsx`:
  - `/` → NewScanPage
  - `/scans` → ScansPage
  - `/scans/:id/report` → ScanReportPage
  - `/scans/:id/diff/:otherId` → ScanDiffPage
- Navigation links in Layout component (nav bar)
