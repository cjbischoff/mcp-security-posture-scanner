# Plan 3.3: CI Pipeline Update

## Scope

Update the GitHub Actions CI workflow to run both backend and frontend tests, add a compose build check, and ensure the deploy workflow gates on all CI passing.

## Requirements

- R-09 (Integration Testing — clearly separated, covers key workflows)
- R-11 (CI/CD — runs tests and deploys on pass)

## Critical items tested

- CI runs both backend and frontend test suites
- CI fails if either suite fails (gate integrity)
- Docker compose build check catches Dockerfile issues
- Deploy only runs on CI success

## Code deliverables

### 3.3.1 — CI workflow update
- Update `.github/workflows/ci.yml`:
  - **Backend job** (existing): lint + unit tests + integration tests
  - **Frontend job** (new): install, typecheck, vitest, build
  - **Docker compose build check** (new): build both images to catch Dockerfile issues early
  - All jobs run in parallel; all must pass

### 3.3.2 — Deploy workflow (no changes needed)
- `.github/workflows/deploy.yml` already gates on CI workflow success
- Verify the `workflow_run` trigger is correct

## Test deliverables

### Integration test
1. Inspect CI yml for correctness: each job has correct steps, working-directory, and dependencies
2. Verify frontend job includes `npm ci`, `npx tsc --noEmit`, `npx vitest run --reporter=verbose`, `npm run build`
3. Verify compose build job uses `docker compose build` with no push step
