# Plan 3.2: Frontend Dockerfile + Nginx

## Scope

Create a production frontend Dockerfile (multi-stage: build with node, serve with nginx) and nginx config that proxies `/api` to the backend service.

## Requirements

- R-08 (Containerization — full system via Docker Compose)
- NFR-7 (Containerized deployment)

## Critical items tested

- Production build completes (`npm run build` in container)
- nginx serves the built app
- `/api/` requests are proxied to backend (CORS, path prefix stripping)
- `docker compose up --build` starts full stack without manual steps

## Code deliverables

### 3.2.1 — Nginx config
- `frontend/nginx.conf`:
  - Serves static files from `/usr/share/nginx/html`
  - Proxies `/api/` to `http://backend:8000` (the Docker Compose service name)
  - Passes through headers (Host, etc.)
  - Default `try_files $uri /index.html` for SPA routing

### 3.2.2 — Frontend Dockerfile (multi-stage)
- `frontend/Dockerfile`:
  - **Stage 1 (build):** `FROM node:22-alpine`, copy source, `npm ci`, `npm run build`
  - **Stage 2 (serve):** `FROM nginx:alpine`, copy built assets from stage 1, copy `nginx.conf`, expose 80
  - CMD is nginx default (starts nginx in foreground)

## Test deliverables

### Smoke test (critical path)
1. `docker compose build frontend` → exits 0
2. `docker compose up -d db backend frontend`, wait for healthy
3. `curl localhost:3000` → returns HTML with React app content
4. `curl localhost:3000/api/health` → returns `{"status":"ok"}` (proxied to backend)

## Test maintenance

```bash
cd backend && uv run pytest -v         # 86 backend tests — must pass

```
