### 1.5.1 — Functional smoke test script
- `backend/scripts/smoke_test.py` — standalone script (not pytest):
  1. Start the stub fixture MCP server as subprocess
  2. POST /api/scans targeting the fixture
  3. Poll until scan completes
  4. Fetch report, assert finding count > 0
  5. Exit 0 on success, 1 with details on failure
- This serves as a functional integration check outside pytest (e.g. for CI or manual verification)
