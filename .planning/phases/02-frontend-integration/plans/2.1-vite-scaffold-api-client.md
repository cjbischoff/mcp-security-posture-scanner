# Plan 2.1: Vite Scaffold + API Client

## Scope

Set up the React + TypeScript frontend project with Vite, install all dependencies, build the centralized API client, configure Vitest + React Testing Library + MSW for mock API testing.

## Requirements

- R-04 (Frontend — functional, centralized API client, tests with run instructions)

## Code deliverables

### 2.1.1 — Vite + React scaffold
- Initialize Vite with React + TypeScript template in `frontend/`
- `frontend/package.json` with dependencies:
  - `react`, `react-dom`, `react-router-dom`
  - `@types/react`, `@types/react-dom`, `typescript`
  - `vitest`, `@testing-library/react`, `@testing-library/jest-dom`, `@testing-library/user-event`, `jsdom`
  - `msw` (Mock Service Worker for HTTP interception in tests)
- `frontend/tsconfig.json`, `frontend/vite.config.ts`, `frontend/index.html`
- `frontend/src/main.tsx` — app entry point with React Router
- `frontend/src/App.tsx` — route definitions: `/` (scan form), `/scans` (list), `/scans/:id/report`, `/scans/:id/diff/:other_id`

### 2.1.2 — Centralized API client
- `frontend/src/api/client.ts` — single module wrapping all backend endpoints:
  - `health()` — GET /api/health
  - `createScan(target)` — POST /api/scans → `{id, status, ...}`
  - `listScans()` — GET /api/scans
  - `getScan(id)` — GET /api/scans/{id}
  - `getReport(id)` — GET /api/scans/{id}/report
  - `diffScans(id1, id2)` — GET /api/scans/{id1}/diff/{id2}
- All functions return typed responses matching openapi.yaml schemas
- Base URL configurable via env var or default to `/api`

### 2.1.3 — MSW mock handlers
- `frontend/src/api/mocks/handlers.ts` — MSW request handlers for all 6 endpoints, returning realistic fixture data matching the stub MCP server's output
- `frontend/src/api/mocks/server.ts` — MSW server setup for tests
- `frontend/src/api/mocks/data.ts` — fixture response data (scan with 6 findings across severities, diff with added/removed/unchanged + drift)

### 2.1.4 — Vitest + RTL config
- `frontend/vitest.config.ts` — test environment set to `jsdom`, setup file pointing at MSW server init
- `frontend/src/test/setup.ts` — MSW server `beforeAll/beforeEach/afterAll` lifecycle

## Test deliverables

### Unit: API client
- `frontend/src/api/__tests__/client.test.ts`
  - `test('createScan returns scan')` — POST to /api/scans returns 201 + scan object
  - `test('listScans returns array')` — GET /api/scans returns array of scans
  - `test('getReport returns findings')` — GET /api/scans/{id}/report returns findings + summary
  - `test('diffScans returns diff')` — GET /api/scans/{id}/diff/{other_id} returns added/removed/unchanged/drift
  - `test('health returns ok')` — GET /api/health returns {status: "ok"}
  - `test('network error handled')` — network failure returns typed error/rejection
