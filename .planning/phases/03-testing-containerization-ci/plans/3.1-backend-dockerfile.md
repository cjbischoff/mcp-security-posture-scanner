# Plan 3.1: Backend Dockerfile

## Scope

Create a production-ready backend Dockerfile using uv, and a .dockerignore. The container must run all 86 tests, serve the API via uvicorn, and connect to Postgres.

## Requirements

- R-08 (Containerization — full system via Docker Compose)
- NFR-7 (Containerized deployment)

## Critical items tested

- Container builds successfully (`docker compose build backend`)
- Container runs all tests (`docker compose run --rm backend uv run pytest -v`)
- Health endpoint responds inside container
- Postgres connection works via DATABASE_URL

## Code deliverables

### 3.1.1 — Backend Dockerfile
- `backend/Dockerfile`:
  - `FROM python:3.13-slim` base
  - Install `uv` via pip
  - Copy `pyproject.toml` and `uv.lock`
  - `uv sync --no-dev` (production only: no pytest, no test deps)
  - Copy `app/`, `alembic/`, `alembic.ini`
  - Expose 8000
  - `CMD ["uv", "run", "uvicorn", "app.main:app", "--host", "0.0.0.0", "--port", "8000"]`

### 3.1.2 — .dockerignore
- `backend/.dockerignore`: `.venv`, `__pycache__`, `*.pyc`, `.pytest_cache`, `.ruff_cache`, `.env`, `*.db`

## Test deliverables

### Smoke test (critical path)
1. `docker compose build backend` → exits 0
2. `docker compose run --rm backend uv run pytest -v` → 86/86 passing
3. Start services: `docker compose up -d db backend`, wait for healthy, then `curl localhost:8000/api/health` returns `{"status":"ok"}`
