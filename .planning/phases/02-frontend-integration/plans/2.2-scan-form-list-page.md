# Plan 2.2: Scan Form + List Page

## Scope

Build the "New Scan" form and the scan list with auto-polling. This is the primary user entry point — submit a target, see the scan run, and navigate to results.

## Requirements

- R-04 (Frontend — functional pages, centralized API client)
- Success criteria 1, 4 from ROADMAP Phase 2 (submit scan, consent toggle)

## Code deliverables

### 2.2.1 — New Scan form
- `frontend/src/pages/NewScanPage.tsx` — form with fields:
  - **Name** (text, required) — human-friendly label
  - **Transport** (select: stdio / http)
  - **Command** (text, shown when transport=stdio) — executable path
  - **Args** (text, shown when transport=stdio) — comma or space-separated
  - **URL** (text, shown when transport=http) — server URL
  - **Allow external** (checkbox, shown when transport=http) — `allow_external` consent flag
- Client-side validation:
  - Name required
  - Command required for stdio
  - URL required for http (validated as parseable URL)
- On submit: calls `api.createScan(target)`, starts polling for completion
- **Loading state:** spinner while scan runs, disable form inputs during scan
- **Error state:** show API error message inline (e.g. "External target requires allow_external")
- **Complete state:** redirect to report page on completion

### 2.2.2 — Scan list page
- `frontend/src/pages/ScansPage.tsx` — table/list of scans:
  - Columns: ID, Target Name, Status (badge), Created, Findings (#)
  - Auto-polls `api.listScans()` every 3 seconds for pending/running scans
  - **Status badges:** pending (gray), running (blue spinner), completed (green), failed (red)
  - Click a scan → navigate to its report page
  - **Empty state:** "No scans yet. Create your first scan."
  - **Loading state:** skeleton rows while data loads

### 2.2.3 — Shared components
- `frontend/src/components/ScanStatusBadge.tsx` — renders status with color
- `frontend/src/components/LoadingSpinner.tsx` — reusable spinner
- `frontend/src/components/Layout.tsx` — app shell with nav bar (New Scan, Scans links)
